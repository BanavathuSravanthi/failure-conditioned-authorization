Research Overview & Architecture

Failure-Conditioned Authorization (FCA) with ILP-Guided Authorization Recovery (IGAR) prevents premature or unnecessary privilege escalation in autonomous agents by enforcing a bounded recovery window on sub-HIGH tool failures.

Core Security Mechanism

When an agent operation below HIGH privilege fails, typical baseline agents immediately seek elevated permissions or request human approval. FCA interposes at the Controller level:

1. Freeze Escalation
Escalation to HIGH tools is frozen immediately. Premature escalation requests are intercepted at the controller without invoking the Approver.
2. Recovery Window
Opens an active recovery window with budget \(K\) (or \(B\) sized by IGAR). Only designated recovery calls execute and decrement the budget.
3. Cost-Gap Sizing (IGAR)
IGAR sizes budget \(B\) dynamically from the ILP-derived permission-cost gap \(\Delta C\). Infeasible Class B tasks receive \(B=0\) to avoid wasted retries.
4. Post-Exhaustion Mode
Once the recovery budget reaches 0, the window closes. In open mode, ordinary calls resume and legitimate escalation reaches the Approver.

IGAR Permission-Cost & Budget Allocation Model (Spec Section 4)

IGAR reuses MiniScope's existing ILP-derived permission-cost structure without re-solving the integer linear program after failure:

Per-Application Cost Hierarchy (\(C_{\text{range}} = \text{cost}(\text{HIGH}) - \text{cost}(\text{LOW}) = 5\)):
• Gmail: LOW=1 (create_draft), MEDIUM=3 (send_draft), HIGH=6 (delete_thread)  →  \(\Delta C = 3 - 1 = 2\)  →  \(B = 1\)
• Slack: LOW=1 (read_channel), MEDIUM=5 (post_message), HIGH=6 (delete_workspace)  →  \(\Delta C = 5 - 1 = 4\)  →  \(B = 2\)
• Drive: LOW=1 (search_files), MEDIUM=4 (upload_file), HIGH=6 (manage_permissions)  →  \(\Delta C = 4 - 1 = 3\)  →  \(B = 2\)

Integer Round-Half-Up Budget Formula:
$$\text{If not feasible (Class B): } B = 0 \quad \text{Else: } B = \text{clip}\left(1 + \left\lfloor \frac{2(K_{\max} - 1)\Delta C + C_{\text{range}}}{2 C_{\text{range}}} \right\rfloor, 1, K_{\max}\right)$$
