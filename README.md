# Failure-Conditioned Authorization (FCA) with IGAR

Academic research implementation of Failure-Conditioned Authorization (FCA) and Information-Guided Authorization Recovery (IGAR).

## Project Overview
This repository investigates whether bounded recovery following a failure below HIGH privilege can prevent unnecessary privilege escalation while preserving legitimate escalation when HIGH privilege is genuinely required.
